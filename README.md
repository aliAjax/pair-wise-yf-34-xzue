# 无人机飞行计划审批与空域协调系统

标准库独立项目。系统记录运营方计划、航线、载荷、高度、人口风险和应急方案，检查临时禁飞区、高度范围、人口风险以及相邻有效计划冲突。续航放行按机型资料核算能源：相邻航点直线距离累加折算耗时，乘审核员填写的 1.0–1.5 风阻系数后加安全返航分钟，不得超过满电时长；备用降落点不得落入生效限制。审核结果支持离线编号幂等回传，计划变更会使原批准失效并生成通知。

## 运行

```bash
python3 app.py --db drone_airspace.db
```

默认监听 `127.0.0.1:8205`，首页 `/`，健康检查 `/health`。

身份头为 `X-User-Id`、`X-Role`；运营方还需 `X-Operator`。角色：`viewer`、`operator`、`airspace_reviewer`、`commander`、`auditor`。

## 主要接口

- `POST /api/models`、`GET /api/models`：登记与查询机型资料（巡航速度 km/h、满电时长分钟、安全返航分钟）。
- `POST /api/restrictions`：新增临时限制或禁飞区。
- `POST /api/plans`：创建飞行计划，可补选 `model_code`（已登记机型）和 `alternate_point`（备用降落点）。
- `GET /api/plans/{id}/check?wind_factor=1.2`：检查硬约束、续航放行和相邻交通冲突。
- `POST /api/plans/{id}/submit`、`approve`、`reject`：提交和审核；审核使用 `offline_id` 保证断网重连幂等，`approve` 可带 `wind_factor`（1.0–1.5，默认 1.0）。
- `POST /api/plans/{id}/change`、`cancel`：版本化变更与取消，并生成通知。
- `GET /api/notifications`、`POST /api/expire`：通知与到期处理。
- `GET /api/state`：按角色返回计划、限制、机型和公开信息。

## 续航放行规则

- 航线能源：相邻航点球面直线距离累加 ÷ 巡航速度 × 风阻系数（审核员填写，1.0–1.5）＋ 安全返航分钟 ≤ 满电时长；超时退回并在错误中说明还差多少分钟，属硬约束，紧急授权不能覆盖。
- 备用降落点落入时间重叠且覆盖地面的生效限制时退回（属空域冲突，指挥官可紧急授权）；仅覆盖空中的限制不影响地面降落点。
- 缺少机型或备用降落点的旧计划不能提交，需先通过变更补齐；航线、机型或备用降落点变更后原批准立即失效。
- 计算规则（`endurance.py` 纯函数）、机型与计划数据（SQLite）、办理入口（HTTP API）分开维护。

## 主要局限

空域几何使用经纬度矩形和航线包围盒近似，不包含多边形、椭球距离、地形、实时遥测和完整间隔标准；续航折算使用球面距离和恒定巡航速度，不含实时电量、风场和温度影响。紧急授权只能覆盖空域及交通冲突，不能绕过载荷、高度与续航硬限制。身份头、无签名离线审核以及单机 SQLite 适合原型，生产环境需要 PKI、真实 GIS 引擎和跨机构事件总线。
